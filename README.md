# INDIALINK Android App

Official Android WebView app for INDIALINK patient assistance.

- Website: https://bdpatient.indialink.workers.dev/
- Package: `com.indialink.patient`
- Minimum Android: 7.0 (API 24)
- Version: 1.0.0

The APK is built automatically with GitHub Actions. Open the latest successful **Build INDIALINK APK** workflow run and download the `INDIALINK-Patient-APK` artifact.
